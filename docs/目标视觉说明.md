# 后续功能的目标视觉

本文件只提供外观参考，**不代表当前任务要求**。只有 A 在新留言中明确交办发布清单后，才增加该功能；第一次修复筛选时不要提前实现。

![已确认的完整工作台与右侧清单外观](目标视觉参考.png)

- 银白、浅灰底色与蓝色强调，保留左导航、顶部筛选、中间完整任务列表。
- 生成清单时，在右侧展开窄面板，原任务列表仍能同时看到。
- 六项原始任务中，清单只列尚未完成的五项及各自截止时间；已完成项目不列入。
- 复制按钮只复制清单，不自动发送消息。所有任务都完成时，显示“已经全部准备好了，可以发布”。
- 以 1600×900 桌面视口为录制基准，任务、清单与复制按钮要完整可见，不用缩小字号换取同屏。

`styles.css` 保留这套已确认布局的清单样式。A 已在同一份 PR 的新留言中明确交办发布清单，清单控件与执行逻辑现已按本说明接入：只列未完成事项及截止时间、只复制清单不自动发送消息、全部完成时显示提示语。
